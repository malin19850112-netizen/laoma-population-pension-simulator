# 人口与养老金情景模拟器 · V45公开准备版

广东、湖南、广西的公开数据与条件模拟。适用于电脑上的研究与学习，不是官方预测、专业退休精算或确定财政缺口计算器。

## 第一次使用：先下载，再运行

**[点击下载完整公开版 ZIP](https://github.com/malin19850112-netizen/laoma-population-pension-simulator/archive/refs/heads/main.zip)** · [补充自己省份的方法](docs/补充一个省份的方法.md) · [资料表填写说明](docs/templates/README.md) · [非商业许可](LICENSE.txt)

### 1. 下载并解压

1. 点击上面的下载链接；也可在仓库绿色 **Code（代码）→ Download ZIP** 下载。不需要注册GitHub账号，不需要Git命令。
2. 等待下载完成，在文件管理器找到ZIP，右键选择“全部解压缩”。不要在压缩包预览中直接运行。
3. 打开解压后的 `laoma-population-pension-simulator-main` 文件夹，确认同时有 `人口与养老金情景模拟器.exe`、`app` 文件夹和 `README.md`。

GitHub网页中的文件列表只是源码展示，点击网页里的 `app/index.html` 会看到源码，不会启动APP。

### 2. 打开程序

**Windows桌面方式（已验收的主要使用方式）：** 已安装Microsoft Edge时，双击 `人口与养老金情景模拟器.exe`。不需要运行构建脚本，不需要安装Python或Node.js，不需要管理员权限。启动器使用本机Edge打开独立应用窗口，不是浏览器内核完全独立的安装程序。

**浏览器备用方式：** 在解压后的本地文件夹中打开 `app`，用Edge打开 `index.html`。程序和数据在本机运行；日常查看不需要登录或联网，下载和访问官方来源链接需要联网。其他现代浏览器可尝试，但本次验收以Windows Edge为准；不宣称已验证macOS/Linux桌面启动。

请移动或保留整个文件夹，不能只移动EXE。普通使用者无需打开 `desktop.cs` 或运行 `build-desktop.ps1`。

### 3. 第一次看什么

1. 在省份入口选择广东、湖南或广西。当前不是全国全省资料库，城市资料也不是所有省的全部地市。
2. 进入人口变化，比较2026、2036、2046、2056。先看统计年份和数据性质，再看人数、年龄结构和结论。
3. 调整生育或迁移情景，观察未来结果怎样变化。**2026也是模拟；2025实际总人口与细年龄重建不是同一种数据。** 实际统计不随情景切换。
4. 进入养老金，先选择职工或居民制度，再比较三种情景。劳动年龄人口不等于实际缴费人数，老年人口不等于退休领取人数；缴费不足额也不等于最终基金缺口。
5. 查看出生死亡、来源和缺项说明；导出当前数据后保留年份、单位、来源及假设列。未知不是0，不据此认定养老金一定停发。

### 4. 打不开或看不懂怎么办

|遇到的情况|处理方式|
|---|---|
|提示找不到Edge或app文件夹|先完整解压，确认EXE与app在同一文件夹；使用本地app/index.html备用入口。启动器只检查常见Edge安装位置，自定义安装可能无法识别。|
|Windows或安全软件提示未知发布者|EXE未数字签名。不要关闭安全防护或强行绕过拦截；可先核对本仓库来源，改用本地HTML入口。|
|网页只显示代码|你打开的是GitHub文件预览；请下载解压后打开本地文件。|
|文件夹中找不到EXE|确认下载了整个ZIP而非单个文件，检查安全软件通知；不要为了恢复文件关闭安全软件，可用HTML入口。|
|某省、某年份或市级预测为空|先看“缺项与范围”，当前可能没有可靠资料或公开版未提供；不是0，也不是自动联网补数据。|
|旧研究方案无法恢复|方案与数据指纹不一致时会拒绝导入；保留旧文件，在新版本重新选择参数并保存，不手改校验字段。|
|中文网页出现奇怪翻译|关闭浏览器对本仓库的自动翻译，以中文原文为准。|

不能解决时可在仓库 **Issues（问题）** 提交：系统和浏览器版本、下载时间、操作步骤、错误文字与必要截图。不要上传个人身份证、社保账户、密码或私人明细。公开问题会被其他人看到；商业授权请使用文末邮箱。

## 与本地完整版的区别
- 地图改为三省文字入口，不分发地图几何、地图截图。
- 不包含旧研究的市级未来数组与排名。37个城市实际资料继续保留，缺项标明；没有用全省结果分摊城市。
- 不包含原网页、PDF、年鉴、图片、旧版APP和核查下载包；改用官方来源链接及必要整理数值。
- 省级人口模型、养老金计算及历史回测未因打包调整，数值回归验收通过。
- 独立Edge配置目录和浏览器存储键，不覆盖本地完整版的研究方案。旧版方案指纹不同，会拒绝导入。

## 已知限制
- 2025细年龄是重建估计；2026也是模拟，不能冒充当前实际人口。
- 广东出生100.3万有省政府原文依据；此前PDF为103.3万，原因未核定，双版本保留。
- 湖南居民实缴人数缺项。广西缺同口径实缴、纯缴费收入与待遇支出，无法给出四阶段资金覆盖率和最终缺口。
- 广西居民领取人数756.19万与707.15万存在官方版本差异，未擅自解释或合并。
- 老年人口不等于退休人数，劳动年龄人口不等于实缴人数。迁移残差含统计差异；补充资金增长不是政府承诺。
- 历史回测误差不能当未来准确率。没有保证1949年以来每年每市资料齐备。

## 补充自己的省份

**不懂代码也可以整理资料；但填好表不会自动出现在APP里。** 当前没有输入省名搜索、上传CSV或自动生成新省的功能。

1. 先复制一份下载目录，保留原版。仅收集一个省的官方公开汇总数据，不提交个人社保或缴费明细。
2. 在 `docs/templates` 中复制四张空表，用Excel或其他表格工具填写；先看[中文字段说明](docs/templates/README.md)。表头只有英文是正常的，空表没有预填假数据。
3. 优先整理最新实际人口和年龄结构、过去约20年的变化；养老金分别整理职工和居民的实缴人数、领取人数、缴费收入、待遇支出及补充来源。每个数记录统计口径、年份和出处，未知留空写原因。
4. 不懂代码者可通过Issues说明省份与资料范围，提供官方链接和已核对的公开汇总表；这是资料贡献，不代表作者承诺接入或审核通过。
5. 开发者按[完整方法中的接入位置及验收要求](docs/补充一个省份的方法.md)处理数据、代码分支、图表和导出，完成历史回测与原三省回归检查。不能只改省名或套用广东参数。


请先阅读[补充一个省份的方法](docs/补充一个省份的方法.md)，按[空白资料表](docs/templates/)整理人口、养老金、来源和假设，再由开发者接入和验收。指南说明最新实际基线、过去20年原因分析、四阶段推演、实缴与退休转换、代码位置以及缺项处理。

现版没有输入省名自动搜索或CSV自动导入功能；模板仅用于资料核对。资料不足时保留实际展示和缺项，不强行输出预测或养老金缺口。代码许可仍以LICENSE.txt为准。
