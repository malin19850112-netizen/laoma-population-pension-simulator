# 人口与养老金情景模拟器 · V45公开准备版

广东、湖南、广西的公开数据与条件模拟。适用于电脑上的研究与学习，不是官方预测、专业退休精算或确定财政缺口计算器。

## 下载

在仓库点击 **Code → Download ZIP**，解压后按下方步骤打开。请保留整个目录，不能只下载EXE。

## 使用
解压整个文件夹，双击“人口与养老金情景模拟器.exe”（Windows，需要已安装Microsoft Edge）。也可用现代浏览器打开 `app/index.html`。不要只复制EXE。无需安装依赖、登录或联网运行。查看官方来源链接需要联网。

1. 在省份入口选广东、湖南或广西。
2. 查看人口变化，比较2026、2036、2046、2056；实际2025基线不随情景变化。
3. 进入养老金，分别查看职工和居民制度。缴费覆盖待遇、覆盖基金总支出、列示来源后待平衡及最终缺口不是一个指标。
4. 出生死亡页查看常住、户籍和未明确口径；导出会保留数据性质、来源、假设与冲突。

## 与本地完整版的区别
- 地图改为三省文字入口，不分发地图几何、地图截图。
- 不包含旧研究的市级未来数组与排名。37个城市实际资料继续保留，缺项标明；没有用全省结果分摊城市。
- 不包含原网页、PDF、年鉴、图片、旧版APP和核查下载包；改用官方来源链接及必要整理数值。
- 省级人口模型、养老金计算及历史回测未因打包调整，数值回归验收通过。
- 独立Edge配置目录和浏览器存储键，不覆盖本地完整版的研究方案。旧版方案指纹不同，会拒绝导入。

## 已知限制
- 2025细年龄是重建估计；2026也是模拟，不能冒充当前实际人口。
- 广东出生100.3万有省政府原文依据；此前PDF为103.3万，原因未核定，双版本保留。
- 湖南居民实缴人数缺项。广西缺同口径实缴、纯缴费收入与待遇支出，无法给出四阶段资金覆盖率和最终缺口。
- 广西居民领取人数756.19万与707.15万存在官方版本差异，未擅自解释或合并。
- 老年人口不等于退休人数，劳动年龄人口不等于实缴人数。迁移残差含统计差异；补充资金增长不是政府承诺。
- 历史回测误差不能当未来准确率。没有保证1949年以来每年每市资料齐备。

## 目录
`app/`：可直接运行的HTML、CSS、JavaScript及必要结构化数值。
`desktop.cs`、`build-desktop.ps1`：可复核的Windows启动器源码与构建脚本。
`docs/`：数据性质、来源与发布边界。
`SHA256SUMS.json`：文件完整性清单。

## 补充自己的省份

请先阅读[补充一个省份的方法](docs/补充一个省份的方法.md)，按[空白资料表](docs/templates/)整理人口、养老金、来源和假设，再由开发者接入和验收。指南说明最新实际基线、过去20年原因分析、四阶段推演、实缴与退休转换、代码位置以及缺项处理。

现版没有输入省名自动搜索或CSV自动导入功能；模板仅用于资料核对。资料不足时保留实际展示和缺项，不强行输出预测或养老金缺口。代码许可仍以LICENSE.txt为准。
